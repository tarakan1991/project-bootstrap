## Шаблон отчёта в задаче

По завершении работы — комментарий в задачу:

```
Сделано: <что именно, 1–3 строки>
Как проверить: <шаги или команда>
Не сделано / хвосты: <что осталось и почему; «нет» если чисто>
```

## Definition of Done

- Изменения влиты в `main` по регламенту `git-workflow.md`, проверка зелёная
- Изменения проверены{{ (при автодеплое — на проде)}}
- Отчёт в задаче написан, задача закрыта по правилу выше
- Затронута архитектура → в том же PR обновлён `docs/architecture/*`; нетривиальное решение → ADR
