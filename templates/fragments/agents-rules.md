# Строки раздела «Глобальные правила» в AGENTS.md

Набираются по ответам. Включать **только** соответствующие выбранному; лишние строки — это шум, за который агент платит вниманием.

## Всегда

- Язык коммитов и документации — русский.
- **Секреты** (токены, пароли, адреса серверов, ключи доступа) в репозитории и доках хранить НЕЛЬЗЯ. Переменные объявляются в `env.example` без значений.
- **Тест — контракт.** Падает тест — чинится код; менять тест ради того, чтобы проверка прошла, нельзя.
- **Разрушающее изменение схемы данных** не едет вместе с тем изменением, которое его вводит; перед операцией, способной потерять данные, — резервная копия. Подробнее — `docs/workflow/conventions.md`.
- Что нельзя трогать без согласования → `docs/workflow/conventions.md`.

## По стратегии ветвления

| Стратегия | Строка |
|---|---|
| `trunk` | Пишем сразу в `main` мелкими частями; незаконченное — за выключателем в коде, не в отдельной ветке. |
| `branch-per-task` | Прямая запись в `main` не используется — только через ветку и предложение изменений. |
| `env-branches` | Прямая запись в постоянные ветки не используется. Изменение идёт `{{ВЕТКА_ТЕСТ}}` → `{{ВЕТКА_ПРОД}}`, никогда обратно. |

Полностью — `docs/workflow/git-workflow.md`.

## По задачам

| Вариант | Строка |
|---|---|
| `none` | — строка не нужна |
| `hosting` / `external` + «нет задачи — нет работы» | Нет задачи — нет работы (исключение — тривиальные правки доков и мелочи). |
| `hosting` / `external` + «крупное с задачей» | Крупная работа начинается с задачи; мелочь можно без. |

## По ревью

| Вариант | Строка |
|---|---|
| `none` | — строка не нужна |
| `self-check` | Перед вливанием — чек-лист из `git-workflow.md`. |
| `ship-show-ask` | По каждому изменению решаем: влить сразу, влить и показать, дождаться ответа — критерии в `git-workflow.md`. |
| `required` | Вливаем только после согласия другого участника. |

## По проверке

| Вариант | Строка |
|---|---|
| `none` | — строка не нужна |
| `manual` | Перед вливанием — полная проверка одной командой (`conventions.md`). |
| `ci` | Вливаем только с пройденной автоматической проверкой; правки только документации её не гоняют. |

## По выкату

| Вариант | Строка |
|---|---|
| `none` | — строка не нужна |
| `manual` | Выкат — отдельное действие по сценарию из `runbooks.md`. |
| `gated` | `main` = «готово к выкату»; выкат запускает человек по `runbooks.md`. |
| `auto` | **Вливание в `main` = выкат к пользователям.** Проверяем результат на проде. |

## Definition of Done

Строка собирается из включённого: изменение затрагивает архитектуру → в том же изменении обновлён `docs/architecture/*`; нетривиальное решение → новый ADR{{; отчёт в задачу}}.
