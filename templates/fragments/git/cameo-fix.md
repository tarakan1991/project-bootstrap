## Быстрая правка не по теме

Понадобилось поправить мелочь, пока сидишь в незаконченной задаче? **Не** коммить её в текущую ветку и **не** ответвляйся от неё — иначе утащишь свои невлитые коммиты в посторонний набор изменений.

```bash
git stash push -- путь/к/файлу        # если уже наредактировал в своей ветке
git fetch origin
git checkout -b docs-краткое-описание origin/main
git stash pop
# правка → коммит → предложение изменений → вливание
git checkout 42-краткое-описание       # вернулись к своей задаче
```
