{{### Блок для работы сразу в общей ветке

- Начинаешь работу — всегда от свежего состояния общей ветки.
- Коммиты мелкие и частые; неделя работы локально вливается больно.
- Незаконченное — за выключателем в коде, а не в отложенных коммитах.
- Историю после `push` не переписываем: `git reset` и `--force` ломают состояние у всех.
}}

{{### Блок для работы в отдельных ветках

- Начинаешь работу — всегда от свежего состояния {{общей ветки / тестовой ветки}}.
- Ветки живут день-два; длинные периодически подтягивают общую под себя.
- Перед вливанием — перенести свои коммиты поверх свежей общей ветки.
- Пуш ветки после переноса коммитов — только `--force-with-lease`, **никогда** `--force`. В своей ветке история переписывается, в общей — нет.
- `merge` между рабочими ветками руками не делаем.
- {{Локальные ветки без удалённой пары: `git fetch --prune`, затем удалить помеченные `[gone]`.}}
- Прямая запись в общую ветку не используется.
}}
