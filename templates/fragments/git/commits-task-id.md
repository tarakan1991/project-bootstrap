## Коммиты

Формат `{{ПРЕФИКС}}-<номер>: описание` — номер задачи в начале каждого сообщения. {{Русский / английский}} язык, без точки в конце, не длиннее 72 символов.

```
{{ПРЕФИКС}}-42: добавляет обработчик регистрации
{{ПРЕФИКС}}-57: исправляет ошибку валидации ключа
```

Сообщение объясняет, **что делает изменение**, а не что делал автор.

**Исключение — работа без задачи.** Тривиальные правки доков и мелочи, для которых задачу не заводят, пишутся без номера: `docs: обновляет README`. Договорённость об исключении важна: без неё формат начинают обходить выдуманными номерами.
