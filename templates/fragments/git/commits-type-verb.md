## Коммиты

{{Русский / английский}} язык, формат `тип: глагол + что делает`. Типы: `feat`, `fix`, `chore`, `docs`, `refactor`. Без точки в конце, не длиннее 72 символов.

```
feat: добавляет обработчик регистрации
fix: исправляет ошибку валидации ключа
docs: обновляет AGENTS.md после рефакторинга
```

Сообщение объясняет, **что делает изменение**, а не что делал автор. «Правки» и «фиксы» — не сообщения.
