## Жизненный цикл ветки

```bash
# СТАРТ — всегда от свежего main
git checkout main && git pull
git checkout -b 42-краткое-описание

# ... работаем, коммитим ...

# ПЕРЕД ВЛИВАНИЕМ — подтянуть main под себя
git fetch origin && git rebase origin/main
# rebase переписал историю → обычный push отлетит, нужен force-with-lease
git push --force-with-lease origin 42-краткое-описание

# открываем предложение изменений: база — main, в описании — что и зачем

# ВЕРНУТЬСЯ ДОМОЙ — обязательный шаг, иначе останешься на влитой ветке
git checkout main && git pull
git branch -D 42-краткое-описание
```

`--force-with-lease`, **никогда** `--force`: первый откажется затирать чужие коммиты, второй затрёт молча.

Последняя строка нужна, если ветка схлопывается в один коммит: тогда git не видит её как влитую и `-d` откажется удалять. Ветки не схлопываются — достаточно `-d`.
