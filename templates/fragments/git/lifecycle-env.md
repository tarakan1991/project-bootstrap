## Жизненный цикл ветки

```bash
# СТАРТ — от свежей ветки тестового контура
git checkout {{ВЕТКА_ТЕСТ}} && git pull
git checkout -b 42-краткое-описание

# ... работаем, коммитим ...

# ПЕРЕД ВЛИВАНИЕМ — подтянуть тестовую ветку под себя
git fetch origin && git rebase origin/{{ВЕТКА_ТЕСТ}}
git push --force-with-lease origin 42-краткое-описание

# предложение изменений: база — {{ВЕТКА_ТЕСТ}}
# влилось → изменение уехало на тестовый контур, проверяем там

# ВЕРНУТЬСЯ ДОМОЙ
git checkout {{ВЕТКА_ТЕСТ}} && git pull
git branch -D 42-краткое-описание
```

**Перенос на прод** — отдельное предложение изменений из `{{ВЕТКА_ТЕСТ}}` в `{{ВЕТКА_ПРОД}}`, после того как проверили на тесте.

`--force-with-lease`, **никогда** `--force`: первый откажется затирать чужие коммиты, второй затрёт молча.
