## Как идёт работа

```bash
git pull                    # начинаем с актуального состояния
# ... работаем, коммитим ...
git pull --rebase           # подтянуть чужое, свои коммиты лягут поверх
git push
```

Правила, без которых схема разваливается:

- **Коммиты мелкие и частые.** Изменение, которое зрело неделю локально, вливается больно и ломает чужое.
- **Незаконченное прячется за выключателем в коде**, а не копится локально. Код на месте, но выключен, пока не готов.
