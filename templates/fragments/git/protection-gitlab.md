## Защита главной ветки

В GitLab это бесплатно, включая свой сервер — включаем сразу. Выполняет владелец репозитория.

1. **Settings → Merge requests:** способ вливания — по договорённости из раздела «Как изменения попадают в общую ветку»; «Pipelines must succeed» — включить; «Skipped pipelines are considered successful» — включить, иначе предложение с правками только документации (пайплайн по правилам не запускается) не сможет влиться.
2. **Settings → Repository → Protected branches:** для каждой постоянной ветки ({{перечислить: общая ветка, либо ветки окружений}}) — «Allowed to push and merge»: **No one** на запись, Maintainers на вливание. Прямая запись закрыта физически. При ветках окружений прод-ветку защищаем строже: вливать в неё может меньший круг.
3. **Обязательное согласие** (Merge request approvals) — платная возможность. Есть Premium → включить нужное число. На бесплатном плане технически не заставить: держимся на договорённости — не вливаем без ответа в комментариях.
