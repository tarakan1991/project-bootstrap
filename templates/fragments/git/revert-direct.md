## Откат

```bash
git revert <sha сломавшего коммита>
git push
```

Историю после `push` не переписываем: `git reset` и `--force` на общей ветке ломают состояние у всех остальных. Ошибка убирается новым коммитом.

**Откат кода не откатывает данные.** Если в изменении была миграция, удаляющая или переименовывающая что-то, возврат кода назад сломает и предыдущую версию: она обратится к тому, чего больше нет. Правило разделения миграций — в `conventions.md`.
