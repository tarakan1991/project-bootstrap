## Откат

Сломавшее изменение откатывается **тем же путём**, что и вливалось:

```bash
git checkout main && git pull
git checkout -b revert-<что-откатываем>
git revert <sha влитого коммита>
git push origin revert-<что-откатываем>
# предложение изменений → вливание
```

Общая ветка напрямую не правится даже в пожар. Единственное исключение — сломана сама автоматика и вливание невозможно: тогда чинит владелец репозитория, осознанно и руками.

**Откат кода не откатывает данные.** Если в изменении была миграция, удаляющая или переименовывающая что-то, возврат кода назад сломает и предыдущую версию: она обратится к тому, чего больше нет. Правило разделения миграций — в `conventions.md`.
